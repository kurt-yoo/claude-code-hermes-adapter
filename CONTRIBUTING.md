# Contributing

Contributions are welcome.

Good contributions include:

- new Claude Code skills converted from Hermes workflows
- safer install behavior
- examples for specific project types
- MCP bridge documentation
- tests for conversion helpers

Please avoid:

- private memories or secrets
- organization-internal paths in public templates
- claims that this bypasses Claude or Anthropic policy
- large prompt dumps that mention unavailable tools without adaptation

## Style

- Keep skills short and procedural.
- Include trigger conditions and verification steps.
- Prefer concrete command examples.
- Use generic paths unless a file is explicitly project-local.
